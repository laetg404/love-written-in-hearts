## ✨ About the project

The project uses parametric equations to generate the coordinates of a heart-shaped curve.

Each point along the curve is decorated with a repeated message, while HSV color conversion generates a rainbow gradient throughout the composition.

The result is a colorful heart made entirely of words.

### Features

- ❤️ Heart-shaped drawing using mathematical equations.
- 🌈 Dynamic rainbow color generation.
- 🧮 Parametric heart curve calculations.
- ✍️ Repeated text rendering along the heart contour.
- 🐢 Animated drawing using Python Turtle.
- 💗 A little digital love letter made for Val.

## 🚀 Getting started

### Requirements

- Python 3.x
- Tkinter support for Python Turtle.

### Installation

Clone the repository:

```bash
git clone https://github.com/laetg404/love-written-in-hearts.git
```

Navigate to the project directory:

```bash
cd love-written-in-hearts
```

Run the script:

```bash
python main.py
```

---

## ⚙️ How it works

1. Initializes a Turtle graphics window with a black background.
2. Generates points using parametric heart equations.
3. Iterates through different scales to create multiple heart-shaped layers.
4. Calculates rainbow colors using HSV color space.
5. Converts the generated colors into RGB values.
6. Writes a romantic message at each calculated position.
7. Repeats the process to create the final composition.
